# Публикация и проверка ресурсов — 11.11.2026

Обновление относительно `0accf7ac` от 26.10.2026. Перенесены исходники календаря,
патчи Google/Codex, настройки терминалов, необязательные шаблоны rclone/KeySwitch
и проверки состояния. Параметры масштаба/расположения экранов и связанные с ними
правки переноса/ужатия окон KWin исключены. KWin-скрипт и эффекты в этом коммите
сохраняют прежнюю версию.

## Что исключено из публикации

Базы/кеш Akonadi, события/задачи/контакты, конфиги аккаунтов, KWallet,
rclone.conf, OAuth client/refresh/access tokens, браузерные/Electron-профили,
история ввода/буфера, журналы и снимки рабочего стола, личные словари и исключения,
бинарники приложений и результаты сборки. Локальные отчёты ревизий не копировались.
Самостоятельные установки CLI и исправления пакетов остаются вне дистрибутива темы.

Экспорт выполнен по списку исходников и нейтральных конфигурационных фрагментов.
Домашние пути заменены шаблонами. Автор коммита использует GitHub noreply.
Gitleaks 8.30.1 получен из официального выпуска с проверкой SHA256; выполнена
проверка публикуемого дерева, дополненная поиском личных путей и OAuth-форматов.
Сохранены публичные сведения об авторах и лицензиях стороннего кода.

В прежнем README стороннего KDE-Rounded-Corners был `sealed_token` сервиса графика
звёзд GitHub. Блок удалён, как и пути экспорта редактора из четырёх SVG. Это данные
стороннего upstream, а не учётные данные пользователя. Старые публичные коммиты
не переписывались. После очистки сканирование текущего дерева не находит секретов.

## Ресурсы в текущей системе

Проверены /proc, состояния/счётчики перезапусков systemd и фактически загруженные
библиотеки. Два замера по 30 секунд, без вмешательства в рабочие окна:

| Компонент | CPU одного ядра в последнем замере | Дескрипторы, начало → конец |
|---|---:|---:|
| edge helper | 0,000% | 14 → 14 |
| appmenu bridge | 0,000% | 6 → 6 |
| Google resource в простое | 0,000% | 24 → 24 |
| rclone | 0,000% | 7 → 7 |
| kded6 | 0,067% | 45 → 45 |
| KeySwitch, два процесса | 0,033% / 0,067% | 21 → 21 / 13 → 13 |

Процессов D/Z/T и failed-служб не обнаружено. У edge/appmenu/rclone NRestarts=0.
Автопатчеры завершаются и простаивают; watchdog между проверками не работает.
В пользовательском systemd обнаружены два таймера: прежний watchdog (2 минуты)
и arch-update. Новых фоновых таймеров это обновление не устанавливает.

Просмотренные короткие QML/QTimer используются для разового отложенного обновления,
анимации или скрытия панелей. Синхронизация календаря — штатные 5 минут Akonadi;
секундного помощника нет. Меню Electron экспортируется по событиям, пассивная
диагностика запуска также не создаёт таймер. Проверка библиотек/сборка запускаются
по необходимости, не непрерывно. Нулевая цифра CPU — точность краткого замера,
не обещание нулевого потребления при синхронизации или взаимодействии.

## Проверки кода

- Свежая изолированная загрузка подходящего upstream-тега и сборка всех трёх
  библиотек Core/Tasks/Calendar. Проверен первый запуск без source/source-tag.
- Собраны `sg-task-done`, `sg-google-tasks-resync` и `calendar-policy` без установки
  поверх работающих программ.
- 9/9 наборов mock-тестов Google прошли на свежих приватных библиотеках, включая
  квоту, освобождение транспорта 150 jobs, restart/OAuth и CRUD событий/задач.
  Fixtures учитывают showHidden/пагинацию и эквивалентный порядок полей RRULE.
  Старые несогласованные fixtures сначала дали три отказа; это отражено в локальном
  отчёте, финальная проверка использует приложенные тесты и fixtures.
- 4/4 проверки постоянного бюджета/паузы API прошли в отдельных процессах с
  отдельным тестовым состоянием. Рабочие файлы квоты не удалялись.
- Проверки синтаксиса поддерживаемых Python 3, shell, JavaScript меню и JSON.
  Старые сторонние Python 2 тесты GTK-модуля не относятся к этой проверке.
- Общий health-check и проверка календаря проходят. Исправлен ложный FAIL JetBrains:
  несколько JAR теперь открываются отдельно. Неустановленный Claude Desktop
  больше не считается устаревшей копией. Health-check возвращает ошибку при FAIL.

Рабочие приложения, KWin и Plasma не перезапускались. Внешний вид на обоих экранах,
анимации, реальный сетевой CRUD и будущий системный update в рамках публикации
заново не проверялись. Суточная утечка/расход батареи краткими замерами не исключены.
