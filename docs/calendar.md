# Календарь и задачи Google

Это необязательная интеграция для Arch/CachyOS. Нужны `akonadi`, `kdepim-runtime`,
`kdepim-addons` (плагин `pimevents`), `merkuro`, `libkgapi`, `kcalendarcore`,
`kwallet`, инструменты сборки CMake/Ninja/ECM и зависимости разработки этих пакетов.
Устанавливать пакеты и подключать учётную запись должен владелец системы.

## Установка

1. Скопируйте `core/` и плазмоид часов по основной инструкции. Настройте Google
   в Merkuro. Токен хранится в KWallet; никакие файлы аккаунта из чужой системы
   не нужны. В параметрах часов включите PIM-события и выберите свои коллекции.
   При использовании Google-праздников отключите дублирующий плагин праздников KDE.
2. Проверьте идентификатор ресурса. Примеры QML и диагностические инструменты
   рассчитаны на `akonadi_google_resource_0`; при другом идентификаторе измените
   обе подписки SignalWatcher в CalendarView.qml и инструменты проверки/policy/resync.
3. Соберите `sg-task-done` через `rebuild-all.py --no-reload`. Сборка опциональна:
   при ошибке основной rebuild продолжается, но выполнение задач из виджета недоступно.
4. Для приватных исправлений запустите
   `python3 ~/.local/share/soft-graphite/native/google-tasks/launch.py --build-only`.
   Первый запуск скачает исходники KDE libkgapi по тегу установленного пакета.
   Лаунчер собирает только Core/Tasks/Calendar; исходники и stamp находятся рядом
   с ним, временная сборка — в `$XDG_CACHE_HOME/soft-graphite/google-tasks`
   (по умолчанию `~/.cache`). Для своей рабочей папки задайте
   `SOFT_GRAPHITE_GOOGLE_BUILD_DIR`. При обновлении проверяются версии зависимостей;
   при неудаче запускается системный ресурс, старые приватные ABI не подмешиваются.
5. Создайте `~/.local/share/akonadi/agents/`, скопируйте туда
   `akonadi/agents/googleresource.desktop`, заменив `@HOME@` своим абсолютным HOME.
   Применение требует следующего входа либо согласованного перезапуска Akonadi:
   он может кешировать старый Exec. Работающий ресурс сам не перезапускайте.
6. Соберите `tools/calendar-policy` через CMake/Ninja в своей рабочей папке.
   Запуск без аргументов только выводит CachePolicy событий и задач. Сохраните этот
   JSON локально для отката; `--apply` задаёт этим коллекциям интервал 5 минут,
   `--restore /путь/к/сохранённому.json` восстанавливает его через Akonadi API.
   Это сознательное изменение локальных коллекций. Google может отказать в записи
   метаданных подписного календаря; проверяйте результат. Базу SQL напрямую не меняйте.
   Новые подписки/списки нужно проверить отдельно. Контакты инструмент не изменяет.
7. После согласованного применения проверьте календарь на каждом экране и выполните
   `python3 -B tools/calendar-sync-health.py`.

## Расход ресурсов и ограничения

Постоянного помощника и секундного таймера синхронизации нет. Обычный планировщик
Akonadi обновляет коллекции раз в 5 минут. Карточки/задачи читает короткоживущий
Python-процесс только при открытии/действии пользователя/сигнале синхронизации.
Подписки D-Bus включены только при открытом виджете. Изменение задачи отправляется
обычной очередью Akonadi. Закрытый виджет не запускает опрос.

Патчи libkgapi исправляют `showHidden`, сохранение фильтров между страницами,
EXDATE/RDATE и освобождение сетевого транспорта завершённых jobs. Отказы квоты
403, ответы 429/503 останавливают запрос и ставят API на паузу минимум 30 минут.
Постоянные локальные пределы на скользящие 24 часа: Tasks 15000 чтений + 1000 записей,
Calendar 30000 + 1000, People 500 + 500. Резерв до 32 записывается атомарно под lock
до отправки HTTP. Повреждённый счётчик блокирует запросы. Не удаляйте
`~/.local/state/soft-graphite/google-api-{budget,cooldown}.json` ради сброса квоты.
Ограничения относятся к этому процессу, а не к другим клиентам OAuth-проекта.

Старый повреждённый кеш исключений повторений обычный incremental sync может
не исправить. `sg-google-tasks-resync` — отдельный диагностический инструмент для
курсоров задач; он не нужен для повседневной работы, без `--apply` ничего не меняет.

Локальный watchdog автора живёт в отдельном проекте и раз в 2 минуты проверяет
зависание ресурса. Он **не включён**: механизм досылки зависит от приватного OAuth
и вспомогательного инструмента. Новый таймер взамен него не устанавливайте.
Секундный `soft-graphite-google-sync.service` не устанавливайте.

Патчи проверены на libkgapi 26.08.3. Настоящее будущее обновление пакетов, суточный
расход батареи и все переходы CRUD на реальном аккаунте не подтверждены. Не выдавайте
mock-тесты и чтение текущих записей за такие проверки.

## Необязательные настройки вне календаря

- `config/konsole/sessionui.rc` — пользовательское переопределение двух действий;
  слейте с существующим `~/.local/share/kxmlgui5/konsole/sessionui.rc`, сохранив другие
  действия. Применяется при следующем запуске Konsole.
- `config/vscode-keybindings.json` — добавьте два правила в свой список keybindings,
  не заменяя остальные. Ctrl+C копирует только при выделении, иначе остаётся SIGINT.
- `config/arch-update.conf` — слейте только UpdateCheckTimeout=300 со своим конфигом.
- `systemd/rclone-gdrive.service` — только шаблон mount для уже настроенного remote
  `gdrive:` и папки `~/GoogleДиск`. Учётные данные настраиваются локально через rclone;
  `rclone.conf` не публикуется. Юнит не включать без желания пользователя. Сетевые
  тайм-ауты ограничивают запросы, но не гарантируют отсутствие зависаний FUSE;
  лимит ожидания ядра из системы автора в этот репозиторий не входит.

## Необязательный KeySwitch

`bin/keyswitch`, `autostart/io.github.olegius88.KeySwitch.desktop` и
`config/keyswitch.json` отражают установку KeySwitch 0.70.0 для RU/EN.
Само приложение и обученные/личные словари не распространяются.
Получите официальный выпуск проекта `olegius88/KeySwitch`, проверьте SHA256 и
распакуйте бинарник/resources/hunspell в `~/.local/opt/keyswitch/0.70.0/`.
Слейте настройки с собственными; списки личных исключений здесь пустые.
В autostart замените `@HOME@`; включать его можно только по выбору владельца.

Wayland требует доступа к uinput. `config/keyswitch-system/` содержит образцы
udev/modules-load; это единственные дополнительные системные файлы, и ставить их
может только пользователь с явным согласием и sudo. Агент не устанавливает их
автоматически. Лаунчер проверяет uinput один раз до запуска и при отказе выходит.
После обновления ядра может понадобиться reboot; не пытайтесь подгружать модуль
другой версии. История и автоматические обновления приложения выключены.

`protect_code` не гарантирует сохранность строковых литералов: автокоррекция может
изменить кавычки и `;`. В таких местах используйте Ctrl+Alt+P для паузы;
Ctrl+Alt+Z отменяет замену. Защита парольных полей зависит от доступного AT-SPI;
в непрозрачных полях и терминалах гарантий нет. Это ограничение текущей установки,
а не обещание безопасного для любого кода автоматического режима.
